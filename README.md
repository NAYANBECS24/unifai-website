# UnifAI — The Unified Operating Layer for Enterprise AI Systems

Connect. Control. Govern. Recover. UnifAI gives organizations one operating layer for AI agents, tools, providers, policies, and resilience.

Developed by **YesPanchi Tech Solutions**.

---

## Highlights

- **Cinematic 3D Video Background**: Ambient fixed video layer with SVG film grain and gradient vignettes.
- **Precision Typography**: Curated combination of **Inter**, **Instrument Serif** (italic accents), and **Manrope**.
- **Interactive Control Console**: Live query typewriter effect, dynamic telemetry counters (Agents, Policies, Providers, Health), and pointer-reactive 3D parallax.
- **Enterprise Sections**:
  - The Problem (4 core gaps in unmanaged AI systems)
  - Core Capabilities (6 enterprise-grade control modules)
  - Self-Healing AI Infrastructure (5-step recovery workflow)
  - System Architecture (Enterprise Agents → UnifAI Engine → Dashboard)
  - Governance & Edge Controls (Virtual keys, OIDC, audit logs)
  - Multi-Provider Support (OpenAI, Anthropic, Bedrock, Vertex, Azure, etc.)
  - Enterprise Telemetry & Verified Uptime
- **Zero Framework Bloat**: Pure vanilla HTML5, CSS3, and modern ES6 JavaScript for instant loading and sub-50ms render times.
- **Vercel Ready**: Pre-configured with `vercel.json` for security headers, clean URLs, and asset caching.

## Local Development & Preview

You can preview the site locally using any static file server:

```bash
# Using npx serve
npx serve .

# Or using Python 3
python -m http.server 3000
```

Then visit `http://localhost:3000` in your browser.

## Deploy to Vercel

### Option 1: Using the Vercel CLI
```bash
npx vercel
```

### Option 2: Using the Vercel Dashboard
1. Go to [vercel.com/new](https://vercel.com/new).
2. Import this GitHub repository.
3. Framework Preset: **Other** (Static HTML).
4. Click **Deploy**.
